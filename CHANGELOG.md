# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- First version, derived from gladys-ttc (TTC Toronto).
- Next departures of every Calgary Transit stop, buses and CTrain, in real
  time, without any key or account (Calgary Transit GTFS-Realtime).
- Status of the CTrain Red and Blue lines, from the Calgary Transit service
  alerts (closures disrupt; detours and other notices do not).
- The closest stops suggested from the house location.
- Stop search by name or number, in the stop list shipped with the image.
- Dashboard widgets, scene triggers and scene actions (Gladys 5.1.0+).
